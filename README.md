# CPGRAMS Statistical Analysis

## Statistical Analysis of E-Governance Performance Metrics

This project analyzes public grievance performance data from the Centralised Public Grievance Redress and Monitoring System (CPGRAMS) using statistical techniques in Microsoft Excel.

## Objectives

- Analyze CPGRAMS grievance performance data.
- Study the relationship between Total Receipts and Total Disposal.
- Analyze Disposal Rate (%).
- Apply correlation and regression analysis.
- Interpret the findings in the context of e-governance and digital public services.

## Dataset

The dataset is an official Government of India dataset provided by the Department of Administrative Reforms and Public Grievances (DARPG) through the Open Government Data (OGD) Platform India.

**Dataset:** Department-wise receipts, disposal and pendency of Public Grievance detailed statistics

**Period:** 01 January 2016 to 01 November 2019

## Statistical Techniques

1. Pearson Correlation Analysis
2. Simple Linear Regression
3. Scatter Plot Analysis

## Key Results

- Correlation between Total Receipts and Total Disposal: **0.95917**
- Regression R²: **0.92**
- Correlation between Total Receipts and Disposal Rate: **-0.042**
- R² for Total Receipts vs Disposal Rate: **0.0018**
